# NFT Marketplace — Virtual Internship (Frontend Simplified)

Built by Chris Brown as part of the Frontend Simplified virtual internship program.

## Features
- Hot Collections carousel (Axios + react-alice-carousel)
- New Items carousel with live countdown timers
- Top Sellers with dynamic author routing
- Explore page with filter, load more, skeleton loading
- Author page with follow button and dynamic routing
- Item Details page with dynamic routing
- AOS scroll animations throughout
