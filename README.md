# NFT Marketplace — Frontend Simplified Virtual Internship

A fully responsive NFT marketplace built as part of the [Frontend Simplified](https://frontendsimplified.com) virtual internship program. Simulates a real-world development workflow including component architecture, live API data, animations, dynamic routing, and team-based Git practices.

## Live Demo

**[https://nft-marketplace-starter.vercel.app](https://nft-marketplace-starter.vercel.app)**

## What's Inside

- **Home page** — Landing hero, Hot Collections carousel, New Items grid, Top Sellers list, Browse by Category
- **Explore page** — Full NFT catalog with sort controls (Low to High, High to Low, Most Liked, Recently Added)
- **Item Details page** — Dynamic routing to individual NFT detail view with countdown timer
- **Author page** — Creator profile with their listed NFTs

## Tech Stack

| Tool | Purpose |
|------|---------|
| React 17 | UI framework |
| React Router v6 | Client-side routing |
| Firebase | Backend / data |
| Axios | API calls |
| AOS (Animate on Scroll) | Scroll animations |
| React Alice Carousel | NFT collection carousel |
| React Icons | Icon library |

## Key Skills Demonstrated

- Reusable component architecture
- Dynamic routing with `useParams`
- Live API data fetching with `axios`
- Sort/filter state management
- Scroll-triggered animations
- Git branching, merge conflict resolution, and pull request workflow
- Vercel deployment

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
```

## Deployment

Deployed on [Vercel](https://vercel.com). The `vercel.json` config handles client-side routing rewrites so all routes resolve correctly on refresh.
